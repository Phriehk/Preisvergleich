Suche, Stern und Aktualisieren am Handy

  1. GitHub-Token erstellen (Link öffnet GitHub).
  2. Name: preisvergleich. Ablauf: z.B. 1 Jahr.
  3. Bei "Repository access" wählst du "Only select repositories" und dein Repository preisvergleich.
  4. Bei "Permissions", "Repository permissions" stellst du Actions und Contents jeweils auf "Read and write".
  5. "Generate token" klicken, den Token kopieren (wird nur einmal angezeigt) und hier einfügen:

Der Token bleibt nur in diesem Browser gespeichert.

Benachrichtigungen aufs Handy

  1. Installiere die kostenlose App ntfy (Android: Play Store, iPhone: App Store).
  2. Tippe in ntfy auf "+", gib dieses Thema ein und tippe auf "Abonnieren":
  3. Öffne dein Repository bei GitHub: Settings → Secrets and variables → Actions → "New repository secret". Name: NTFY_TOPIC, Secret: das Thema von oben, dann "Add secret".
  4. Wähle oben einen Favoriten und lege dort deinen Wunschpreis fest.

Wer das Thema kennt, könnte deine Nachrichten mitlesen. Gib es deshalb nicht weiter.
